# AquaFarm V7.3

نسخة PWA محلية لإدارة ومحاسبة مزرعة الأسماك.

أهم التحديثات: دليل حسابات بترقيم صارم، الأصول الثابتة 11، عمليات جديدة +، قيد يومية + مع آلة حاسبة، تقرير حركة أي حساب بفترة زمنية، وتخصيص واجهة منفصل عن البيانات المحاسبية.


## V8 — حماية مخزن البيانات
- مفتاح البيانات المحاسبية الحالي محفوظ كما هو (`aquafarm_v7`) لتجنب فقد البيانات.
- طبقة حماية مستقلة تنشئ نسخة احتياطية قبل التغييرات الهيكلية المستقبلية.
- الواجهات والتقارير لا ينبغي أن تكتب مباشرة إلى مخزن البيانات.
- الاحتفاظ بآخر 10 نسخ احتياطية محلية.
